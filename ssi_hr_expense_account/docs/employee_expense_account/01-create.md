# Create Employee Expense Account

## Pre-Condition

- None.

## Flow

1. Open the **Human Resource > Expense > Expense Accounts** menu.
2. Click the **New** button.
3. Fill in the required fields:
   - **Employee**: Select the employee whose expense account is being created.
   - **Department**: Automatically filled from **Employee**. Change if needed.
   - **Manager**: Automatically filled from **Employee**. Change if needed.
   - **Job Position**: Automatically filled from **Employee**. Change if needed.
   - **Type**: Select the expense account type.
   - **Date Start**: Enter the start date of the expense account period.
   - **Date End**: Enter the end date of the expense account period.
   - **Currency**: Select the currency for this expense account.
   - **Limit**: Enter the maximum budget amount for this expense account.
4. Click **Save**.

## Post-Condition

- A new record is created in **Draft** status.
- Document number is still **/** (not yet generated).
